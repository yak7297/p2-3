# 다듬이 AI 코딩 도구 사용 과정

- 작업일: 2026-08-25
- 사용 도구: Codex
- 작업 목적: 바닐라 프론트엔드와 Python Vercel Function을 사용하는 AI 웹 서비스 제작

이 문서는 과제 제출용 AI 코딩 도구 사용 증빙입니다. 실제 대화의 주요 요청과 그에 따른 작업 결과를 시간 순서로 요약했습니다. API 키와 같은 민감한 값은 기록하지 않았습니다.

## 대화 화면 증빙

![OpenAI 제안 이후 사용자가 Gemini 사용을 결정한 AI 코딩 대화](screenshots/ai-coding-process.png)

위 화면은 AI 코딩 도구가 처음 제안한 API 연동 방향을 사용자가 검토한 뒤 Gemini로 변경하도록 요청한 과정입니다. 이후 백엔드와 환경 변수 구성을 Gemini 기준으로 수정했습니다.

## 1. 과제 요구사항 분석

**사용자 요청**

> “이런 과제를 해야 하는데 보너스 과제는 일단 건너뛸게 하고 단계별로 알려줘.”

**AI 활용 결과**

- 필수 제출물과 평가 조건을 단계별 작업으로 분리
- 바닐라 HTML/CSS/JavaScript, Python `api/`, Vercel 배포 구조 확인
- 최소 네 개 섹션과 AI 입력·결과 기능을 포함하도록 범위 결정

## 2. 서비스 아이디어와 이름 결정

**사용자 요청**

> “서비스명만 다듬이 이걸로 가자.”

**AI 활용 결과**

- 서비스명을 ‘다듬이’로 확정
- 정중한 이메일, 부탁, 사과, 문의 문장을 상황과 말투에 맞게 다듬는 서비스로 기획
- 목적, 타겟 사용자, 페이지 구성, AI 입력·출력·실패 처리 기준 작성

## 3. 프론트엔드 구현

**사용자 요청**

> “어 해줘.”

**AI 활용 결과**

- 홈, AI 작성기, 사용 방법, FAQ의 네 개 섹션 구현
- 상단 메뉴와 섹션 이동 기능 구현
- 입력 폼, 상황 선택, 말투 선택, 결과 카드, 복사 버튼 구현
- 모바일과 데스크톱에 맞는 반응형 CSS 작성

## 4. Gemini API로 변경 및 연동

**사용자 요청**

> “아니 난 gemini 로 할 거야.”

**AI 활용 결과**

- 백엔드를 Google Gemini API 기준으로 변경
- `api/rewrite.py`에서 `google-genai` 패키지를 이용해 결과 생성
- 프론트엔드가 `fetch('/api/rewrite')`로만 백엔드를 호출하도록 구성
- `.env.local`의 `GEMINI_API_KEY`를 백엔드에서만 읽도록 보안 구조 적용

## 5. API 키 설정과 보안 안내

**사용자 요청**

> “생성은 했는데 그걸 넣어야 하지 않을까 API 키를?”

**AI 활용 결과**

- 실제 키는 `.env.local`에만 입력하도록 안내
- `.env.local`을 `.gitignore`에 포함해 GitHub 업로드 방지
- README와 `.env.example`에는 실제 키가 아닌 변수명과 예시만 기록

## 6. 로컬 오류 진단

**사용자 요청**

> “안 되는데 failed to fetch라는데.”

**AI 활용 결과**

- 정적 화면만 실행하면 `/api/rewrite` Python 함수가 실행되지 않아 요청이 실패하는 원인 확인
- 프론트와 Python API를 함께 실행하는 로컬 개발 서버 구성
- Gemini 패키지 설치와 실제 API 응답을 확인

## 7. VS Code 실행 환경 구성

**사용자 요청**

> “비주얼 스튜디오에서 실행은 안 되는 거니?”

**AI 활용 결과**

- VS Code의 빌드 작업으로 로컬 서버를 실행할 수 있도록 설정
- `Command + Shift + B`로 ‘다듬이 실행’을 선택하는 실행 흐름 제공
- 처음 실행할 때 필요한 Python 패키지를 자동 설치하도록 구성

## 8. 포트 충돌 오류 해결

**사용자 제공 오류**

> “4173번 포트를 이미 사용 중입니다. 실행 중인 다듬이 터미널을 먼저 종료하세요.”

**AI 활용 결과**

- 같은 서버가 이미 실행 중일 때 두 번째 실행이 충돌하는 상황을 설명
- 기존 실행 화면을 사용하거나 기존 터미널에서 `Control + C`로 종료한 뒤 다시 실행하는 방법 안내
- 사용자가 로컬 AI 기능 정상 동작을 확인

## 9. 제출 증빙 준비

**사용자 요청**

> “스크린샷 및 AI 코딩 도구 사용 증빙을 준비한다. 서비스 기획서를 제출 패키지에 포함한다.”

**AI 활용 결과**

- 1440×900 데스크톱 홈 화면 캡처
- 390×844 모바일 홈 화면 캡처
- Gemini 입력과 생성 결과가 함께 보이는 AI 기능 화면 캡처
- README, 서비스 기획서, 본 AI 코딩 로그, 증빙 체크리스트 정리

## 사용자가 확인한 핵심 학습 내용

- HTML은 화면 구조, CSS는 디자인과 반응형, JavaScript는 입력 처리와 화면 갱신을 담당한다.
- JavaScript의 `fetch` 요청은 Python Serverless Function으로 전달되고, Python이 Gemini를 호출한 뒤 JSON 결과를 반환한다.
- API 키는 프론트 코드에 넣지 않고 환경 변수로 관리해야 한다.
- 로컬에서는 통합 개발 서버가 필요하고, 배포 환경에서는 Vercel이 정적 파일과 Python 함수를 함께 제공한다.
- `Failed to fetch`와 포트 충돌은 각각 백엔드 미실행과 중복 서버 실행 여부를 확인해 해결할 수 있다.
